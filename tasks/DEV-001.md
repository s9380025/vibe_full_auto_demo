# REQUIREMENTS
다음을 구현한다:
- `index.html`, 필요한 CSS, 필요한 JavaScript (외부 라이브러리 없음, 별도 Build 없이 브라우저에서 바로 실행)
- 10 x 20 Game Board
- 7종 Tetromino (I, O, T, S, Z, J, L)
- Piece 자동 낙하 (시간 기반)
- 좌/우 방향키 이동
- 아래 방향키 Soft Drop
- 위 방향키 회전
- Space Bar Hard Drop
- Board 경계 및 기존 Block과의 Collision 처리
- Piece Lock (바닥/블록에 닿으면 고정)
- 완성된 Line 제거
- Line 제거 시 Score 증가
- 일정 Line 수 도달 시 Level 증가
- Level 증가에 따른 낙하 속도 증가
- Next Piece 표시(다음 조각 정보를 UI에서 표시할 수 있도록 상태 노출)
- 더 이상 Piece를 배치할 수 없으면 GAME OVER 처리
- RESTART 기능
- START 버튼으로 게임 시작
