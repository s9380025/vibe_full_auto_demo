# ROLE
QA/Test Agent

# OBJECTIVE
`docs/PRD.md`를 기준으로 Tetris Mini Game(main branch, DEV-001 + DESIGN-001 merge 이후)을 독립적으로 검증한다.

# CONTEXT
먼저 아래 문서를 읽는다:
- `docs/PRD.md`
- `docs/PROJECT_RULES.md`
- `docs/PROMPT_TEMPLATE.md`
- `tasks/QA-001.md` (본 문서)

QA Agent는 Development/Design Agent의 완료 보고를 신뢰하지 않고, 최초 PRD 기준으로 독립 검증한다.

# REQUIREMENTS

## Functional
- START
- Board 10x20
- 7 Tetromino
- Auto Drop
- Move Left/Right
- Soft Drop
- Rotation
- Hard Drop
- Collision
- Piece Lock
- Line Clear
- Score
- Level
- Speed Increase
- Next Piece
- GAME OVER
- RESTART

## Design
- Board Layout
- SCORE
- LEVEL
- LINES
- NEXT
- Tetromino 구분
- Game State (Start/Game Over)
- UI 일관성

## Regression
- Design 적용 이후 Core Game Logic 전체 재검증

# CONSTRAINTS
- QA Agent는 제품 Source를 수정하지 않는다.
- 테스트 실패를 임의로 PASS 처리하지 않는다.

# ACCEPTANCE CRITERIA
- PRD Compliance, Functional, Design, Regression 항목 모두 PASS일 때만 Overall PASS.

# VALIDATION
- 가능한 테스트는 정적 코드 검토 및 로직 추적(trace)을 통해 직접 수행한다.
- 자동 테스트가 가능한 항목은 `tests/`에 테스트를 작성한다.
- 정적 검토만 가능한 항목은 그 한계를 명시한다.

# OUTPUT
- Report: `reports/QA-001-REPORT.md`
- 형식:
  ```
  PRD Compliance: PASS / FAIL
  Functional Test: PASS / FAIL
  Design Validation: PASS / FAIL
  Regression Test: PASS / FAIL
  Overall Result: PASS / FAIL
  ```
- FAIL 항목이 있으면 각각에 대해: Test, Expected, Actual, Reproduction, Suspected Cause, Responsible Agent, Recommended Fix
- Commit message: `test: add tetris QA report`
